# 实验室离心机预约台

替代纸本排期的本地预约工具：登记样本的管数、时长、优先级与完成期限，自动分配机台与转子，急样可顶位。

## 使用

直接用浏览器打开 `index.html` 即可（无需服务器）。数据保存在本机浏览器 localStorage，重开浏览器后安排仍在。

## 资源与规则

- **机台**：1–4 号离心机共 4 台
- **转子**：转子 A（24 管，适配 1/2 号机）、转子 B（12 管，适配全部机台）
- 一次预约同时占用一台机 + 一只转子，**机台时段与转子时段都不得重叠**
- 管数超过所有可选转子容量（>24）直接拒绝
- 排程结果必须在完成期限前结束，否则拒绝
- **急样顶位**：急样在期限内无空位时，可顶掉普通预约；被顶者自动改期到其他兼容机台/转子且必须赶得上各自期限。任一被顶者改期失败，则**所有原预约原样保留**，并列出冲突的急样时段

## 代码结构（三层分离）

| 文件 | 职责 |
|---|---|
| `js/store.js` | 样本档案：预约记录存取、localStorage 持久化（无 localStorage 时退化为内存） |
| `js/scheduler.js` | 排期判断：重叠检测、容量/期限校验、找空位、急样顶位与改期方案，纯逻辑不碰 DOM |
| `js/app.js` | 页面操作：表单读取、结果提示、机台/转子看板渲染、取消预约 |
