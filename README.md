# 离心机本地预约台

替代纸本排期的纯本地网页工具：登记样本所需的**管数、时长、优先级、完成期限**，
系统自动分配机器与转子，并处理急样插队。无需安装、无需联网、无需服务器。

## 使用

直接用浏览器打开 `index.html` 即可（双击或拖入浏览器）。
数据保存在本机浏览器 localStorage，**重开浏览器后安排仍在**；
首次打开自动载入 5 笔演示预约，右下角可一键“重置为演示数据”。

## 资源与规则

| 资源 | 说明 |
| --- | --- |
| 1、2 号机 | 共用 **A 转子（48 孔）** |
| 3、4 号机 | 共用 **B 转子（24 孔）** |

- 管数 ≤24：两只转子均可；25–48：只能用 A 转子；**>48：直接拒绝**。
- 同一时刻，一台机器、一只转子都只能承接一笔预约（转子只有一只，
  1 号机在用 A 转子时，2 号机同刻也不能用）。
- 同一人不得同时占两台机（急样也不能顶掉本人的预约）。
- 营业时段 08:00–22:00，排期粒度 15 分钟；完成时刻不得晚于完成期限。
- **急样顶换**：急样可顶掉普通预约，但被顶预约必须能换到兼容机器
  （可带兼容转子，必要时连锁顺延其他普通预约），且新时段仍在其完成期限内；
  任一被顶预约无法满足，则**整笔回滚、所有原预约原样保留**，并逐条列出冲突原因。
  急样不能顶急样。

## 代码结构（三层分离）

```
index.html        页面骨架
styles.css        样式
js/archive.js     样本档案层：localStorage 持久化、资源字典、演示数据
js/scheduler.js   排期判断层：容量/时段/期限校验、重叠判断、急样顶换（带回溯的连锁改排）
js/app.js         页面操作层：表单、时间轴、清单、详情与取消
test/             Node 逻辑测试与页面冒烟测试（不参与页面运行）
```

排期层不碰 DOM 与存储，页面层不含任何排期规则，便于单独测试与替换。

## 演示场景（基于内置演示数据，均为“今天”）

1. **正常登记**：任意空闲时段提交普通预约，自动落到第一台兼容机位。
2. **容量拒绝**：管数填 60 → 提示超过最大转子容量，直接拒绝。
3. **转子串用拦截**：登记 30 管、9:00–10:00（S-101 正用 A 转子）→ 普通预约被拒绝，
   因为 1、2 号机共用一只 A 转子。
4. **急样顶换成功**：登记 30 管、急样、14:00–14:30、期限 14:30
   （S-105 此时占 M1/RA，20 管）→ S-105 被顶后带 B 转子换到 3/4 号机同时段，
   仍早于其 15:00 期限；时间轴上 S-105 变为黄色“改排”。
5. **急样顶换失败（原样保留）**：先点“重置为演示数据”；删掉 S-101 后以同样参数重登
   （张磊、40 管、9:00–10:00），但**期限填 11:00**；再登记 40 管、急样、9:00–10:00、
   期限 10:00 → S-101 只能顺延到 10:00 之后（S-103 占着转子到 10:45），
   60 分钟时长将错过其 11:00 期限 → 顶换失败，**所有原预约原样保留**并逐条列出冲突。
6. **同人撞车**：以“张磊”名义再约 9:15 开始的任意预约 → 提示同一人不能同时占两台机。
